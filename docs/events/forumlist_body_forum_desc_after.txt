PROJECT: phpBB (PHPBB)
ISSUE TYPE: Improvement
SUMMARY: New template event forumlist_body_forum_desc_after
PRIORITY: Minor
COMPONENT: Events
AFFECTS VERSION: 3.3.x

TYPE
====
Template event

LOCATION
========
styles/prosilver/template/forumlist_body.html, in each forum row's
list-inner block, immediately after the forum description and before the
moderators line.

3.3.x:

	<a href="{forumrow.U_VIEWFORUM}" class="forumtitle">{forumrow.FORUM_NAME}</a>
	<!-- IF forumrow.FORUM_DESC --><br />{forumrow.FORUM_DESC}<!-- ENDIF -->
	{% EVENT forumlist_body_forum_desc_after %}
	<!-- IF forumrow.MODERATORS -->
		<br /><strong>{forumrow.L_MODERATOR_STR}{L_COLON}</strong> {forumrow.MODERATORS}
	<!-- ENDIF -->

master:

	<a href="{forumrow.U_VIEWFORUM}" class="forumtitle">{forumrow.FORUM_NAME}</a>
	<!-- IF forumrow.FORUM_DESC --><span class="forum-desc">{forumrow.FORUM_DESC}</span><!-- ENDIF -->
	{% EVENT forumlist_body_forum_desc_after %}
	<!-- IF forumrow.MODERATORS -->

PURPOSE
=======
Lets extensions add a line of their own below a forum's description on
the board index and in subforum lists, for every forum row, whether or
not the forum has a description, moderators or subforums.

USE CASE
========
phpbbmodders/feedlinks shows a forum's Atom and RSS feed links below its
description ("Subscribe to the feed, available in Atom or RSS format."),
as phpBB.com does by hand in its forum descriptions.

The existing events in the row do not fit:
- forumlist_body_forum_image_before/prepend/append/after sit before the
  forum name, and only fire when the forum has an image.
- forumlist_body_subforums_before/after only fire when the forum has
  subforums listed.
- forumlist_body_forum_row_append is after the whole <dl>, outside the
  forum's cell, so the content lands below the row instead of under the
  description.

Without this event the extension appends its rendered HTML to the
FORUM_DESC template variable in core.display_forums_modify_template_vars,
which puts markup inside a value styles treat as the description text.
